# Проблемы реверса (отложенные)

Файл для отслеживания проблемных функций/полей, которые мешают нормальному
именованию или заполнению структур. Каждая запись — «что не так» + «почему
отложено» + «что нужно сделать при возврате». Обрабатываем пачками позже.

Формат идентификатора: `<Класс> <адрес или смещение>`.
