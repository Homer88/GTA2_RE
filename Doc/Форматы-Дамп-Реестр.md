## 7. Карта (GMP) — сжатые карты DMAP/CMAP → city_scape

Документировано официально (SOFT/gta2formats/GTA2 Map Format.doc, DMA v8.2) и подтверждено дампом
(см. ниже «функции карты в dump»). Реализовано в Tools/core (GmpFile::decodeCompressedMap).

Структура файла .gmp: `GBMP` + word-версия + секции (name[4] + size:uint32 + data).
Секции карты: `UMAP` (несжатая, 8 слоёв), `CMAP` (сжатая 16-бит, PS2), `DMAP` (сжатая 32-бит, PC).
Порядок секций произвольный; любой инструмент должен сначала искать UMAP, затем DMAP/CMAP.

Блок карты (12 байт): `uint16 left,right,top,bottom,lid; uint8 arrows; uint8 slope_type`.
- `left/right/top/bottom`: биты 0–9 = tile graphic, 10 = wall, 11 = bullet-wall, 12 = flat, 13 = flip, 14–15 = rotation.
- `lid`: биты 0–9 = tile, 10–11 = lighting, 12 = flat, 13 = flip, 14–15 = rotation.
- `slope_type`: биты 0–1 = ground (0 air, 1 road, 2 pavement, 3 field), биты 2–7 = уклон (0 none, 1..63).
- `arrows`: биты 0–3 зелёные (left/right/up/down), 4–7 красные.

### Сжатая карта (DMAP/CMAP)

```
struct {
  uint32/16 base[256][256];      // смещение каждой колонки (в словах от начала column)
  uint32/16 column_words;        // число слов (dword) в column
  uint32/16 column[N];           // колонки
  uint32/16 num_blocks;          // число блоков
  block_info block[M];           // 12 байт каждая; блок 0 всегда пустой
} compressed_map;
```

**Порядок колонок НЕ совпадает с (x,y)** — смещение колонки клетки (x,y) берётся из `base[y*256+x]`.
Каждая колонка: `UInt8 height; UInt8 offset; UInt16 pad; UInt32 blockd[height-offset];`
- Допустимые уровни клетки: z ∈ [offset, height-1] (включительно). При z<offset или z≥height — блок пуст.
- Количество данных блоков колонки = `height - offset`, длина в словах = `1 + (height-offset)`.
- `blockd[i]` — номер записи в `block[]` для уровня z = offset+i.

Декодирование клетки (x,y):
```
idx = base[y*256+x]; raw = column[idx];
h = raw & 0xFF; o = (raw >> 8) & 0xFF;
for z in [o, h):  city[z][y][x] = block[ column[idx+1+(z-o)] ];   // 16/32 бит по типу
```

Игра хранит column/block с запасом на рост: column_words + 32 слова и num_blocks + 200 записей
(проверки в MapRelatedStruct_CreateMap, map.cpp 0x1806/0x1811).

**Хвост RGEN**: расхождение «0xcc70 vs 0xcc62» (адрес начала token-хвоста) остаётся открытым — для
подтверждения нужны фактические адреса массивов Array_H/Array_V из Ghidra-проекта пользователя.

| Строка (.c) | Имя | Что это |

**Энкодер сжатых карт** (Tools/core, `GmpFile::encodeCompressedMap`): зеркально декодеру —
для каждой клетки диапазон [o,h), колонка = слово [height|offset<<8] + blockd[],
одинаковые колонки/блоки совмещаются, блок 0 = пустой. Правка тайлов
(`SetBlock`/`MarkCityDirty`) при Save() перекомпрессирует DMAP/CMAP; без правок секции
пишутся сырыми (byte-identical). 17 карт из bin/data проходят byte-identical roundtrip.
