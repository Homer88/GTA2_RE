# Дампы 
  будут лежать в каталоге dump

# требование к проекту
  каждый клас будет лежать в отдельной папке  например
  menu  лежит в каталоге menu.
  каждая папка это отдельный lib. Сделана так что бы оптимизировать компиляцию.

# revers проекты
    re_file - тут лежат файлы проекты от программ. зампрещено заходить туда по причине нет необходимости.


# Настройки cmake

    1. все откомпилированы файлы дожны  копироваться в bin
    2. будут дописываться инструменты (пока нет необходимости)
    3. стандарт C98  для кода

# Структура проекта 

	3dfx   	 			- Движок Vodo 3DFX
	d3ddll 	 			- Движок Directx 
	dmaglide 			- Движок OpenGL 1.1
	dmavideo 			- Работа с видео картой
	mmsds3dh 			- Звук 3d
	polygon  			- Полигоны 2D
	binkw32  			- видео плаер 
	d3dpoly  			- вроде бы как  полигоны 3D 
	gta2     			- все что касается игры 
		---|Game   		- Все что касается игры  классы игрок и пешеходы и машины
		---|Engine 		- Игровой движок (как загружать файлы работать с памятью с сетью и т.д.)
	gta2manager    		- Конфигуратор игры
	mms32  				- Звуковой движок (sfx, сэмплы)
